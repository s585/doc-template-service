## Краткая формулировка

Отдельной задачей подготовить проект к модульной декомпозиции через `Spring Modulith`, чтобы в дальнейшем упростить выделение частей системы в микросервисы.

## Что должно войти в задачу

- фиксация application modules;
- настройка `Spring Modulith`;
- описание и проверка allowed dependencies;
- перенос filestorage интеграции в отдельный инфраструктурный модуль;
- модульные тесты границ;
- подготовка generation-модуля после завершения соответствующего функционала.

## Ограничения

- не выполнять в рамках текущей фичи;
- не смешивать это с дальнейшей реализацией template / generation use cases;
- не использовать `shared` как место для доменных моделей.
