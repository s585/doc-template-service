Константа
+ форматирование
Общая структура
{
  "id": "uuid",
  "key": "string",
  "type": "string", fileName / field / table /
  "value": {
    "type": "string", field / reference / constant
    "format": "string", (или тут фиксировать формулу в формате date_trunc({$value$})
    "source":{
      "referenceTableId":"uuid",
      "referenceFieldName":"string",
      "path":"string",
      "value":"string"
    }
  }
}
Структура RULE
{
  "op":"string", //операция сравнения
  "type":"string", //operation ИЛИ primitive
  "args":[
    {
      "op":"string",
      "type":"string",
      "path":"string", //путь через дот нотацию
      "args":[{"type":"string", "value":"string"}]
    }
  ]
}
3.	Маппинг для константы (вычисляемого значения - даты)
{
  "id": "uuid",
  "key": "sign_date",
  "type": "field",
  "value": {
    "type": "constant",
    "format": {
      "op":"dateToString",
      "type":"operation",
      "args":[
        {
          "type":"primitive",
          "value":"<<dd>> MON yyyy"
        },
        {
          "type":"primitive",
          "value":"$source"
        },
      ]
    },
    "source":{
      "value":"${now()}"
    }
  }
}
4.	Маппинг для поля объекта
{
  "id": "uuid",
  "key": "deal_num",
  "type": "field",
  "value": {
    "type": "field",
    "format": null,
    "source":{
      "type":"string",
      "path":"source.doc_number"
    }
  }
}

Маппинг для лукапа поля (с предзаполнением, если поле пустое)
{
  "id": "uuid",
  "key": "deal_num",
  "type": "field",
  "value": {
    "type": "field",
    "format": null,
    "source":{
      "type":"string"
      "path":"source.organization$c.name",

    }
  }
}
